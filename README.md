# CareerOS

An AI-powered career management platform for students and early-career developers.

## Goal

CareerOS helps users:
- Track job and internship applications
- Analyze job descriptions
- Identify skill gaps
- Prepare for interviews
- Track career progress

## Tech Stack

Frontend:
- React
- TypeScript
- Tailwind CSS

Backend:
- Node.js
- Express

Database:
- PostgreSQL

AI:
- Python
- FastAPI
- LLM API
